# 🏆 SPORT CLUB MANAGEMENT SYSTEM

## 📌 Project Description

**Sport Club Management System** — Java бағдарламалау тілінде жасалған спорт клубын басқару жүйесі.

Бұл жобаның негізгі мақсаты — спорт клубындағы спортшыларды, командаларды, жаттықтырушыларды және жарыстарды басқару. Бағдарлама Java Collections Framework мүмкіндіктерін пайдаланып, ақпаратты сақтау, іздеу, өзгерту, жою және сұрыптау операцияларын орындайды.

## 🎯 Project Objectives

- Спортшылар туралы ақпаратты сақтау.
- Командалар мен жаттықтырушыларды басқару.
- Жарыстар туралы ақпаратты сақтау.
- Спортшыларды ID бойынша іздеу.
- Спортшылардың рейтингін сұрыптау.
- Коллекциялар арқылы деректерді өңдеу.

## ⚙️ Technologies Used

## 🔹 Java Collections

### 1. ArrayList
Спортшылар тізімін сақтау үшін қолданылады. Элементтерді қосу, алу, өзгерту және жою мүмкіндіктері бар.

### 2. LinkedList
Спорт клубындағы әрекеттер тарихын сақтау үшін қолданылады. `addFirst()`, `addLast()`, `getFirst()` және `removeFirst()` әдістері пайдаланылады.

### 3. HashSet
Қайталанатын спортшыларды болдырмау үшін қолданылады. `equals()` және `hashCode()` әдістері спортшылардың ID мәндері бойынша бірегейлігін тексереді.

### 4. HashMap
Спортшыларды бірегей ID арқылы сақтау және іздеу үшін қолданылады. `put()`, `get()`, `remove()`, `containsKey()` және `entrySet()` әдістері пайдаланылады.

## 🔍 Additional Features

- Спортшыларды рейтинг бойынша сұрыптау.
- Аты бойынша спортшыны іздеу.
- Рейтингі 90 және одан жоғары спортшыларды сүзгілеу.
- Коллекцияларды үш түрлі тәсілмен аралау: for, for-each және Iterator.
- Командалар, жаттықтырушылар және жарыстар туралы ақпаратты шығару.

## ▶️ How to Run

1. Компьютерге Java JDK орнатыңыз.
2. GitHub репозиторийінен жобаны жүктеңіз.
3. `Main.java` файлын ашыңыз.
4. Бағдарламаны іске қосыңыз.
